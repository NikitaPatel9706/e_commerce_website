
# 🧶 Crochet E-Commerce Website

## 📌 About the Project
This is a **Crochet E-Commerce Website** developed as part of a project assigned by **iStudio**.  
The website focuses on showcasing handmade crochet products using basic front-end web technologies.

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript  

---

## ✨ Features
- Crochet product showcase  
- Product listing with images and prices  
- Add to Cart functionality (front-end only)  
- Responsive and user-friendly UI  

---

## 🚀 How to Run
1. Download or clone the project  
2. Open `index.html` in any web browser  

---

## 📌 Note
- This is a **front-end only** project  
- No backend, database, or payment integration
